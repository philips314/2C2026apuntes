### Ejercicio 1

La busqueda comienza desde el inodo correspondiente al directorio raíz, es decir, el inodo 2. Al arrancar ahí y entrar recursivamente en cada subdirectorio ('d'), nos aseguramos de recorrer todo el árbol de directorios sin dejar nada fuera. Luego, una vez se obtiene la dir_entry de un archivo regular (sabemos por 'r'), nos fijamos si cumple la condición 'cuya cuenta de enlaces duros sea de dos o más'. Por lo tanto, todos los archivos regulares que cumplan esta condición, estarán en el mapa.  

Además, es seguro recorrer recursivamente porque se saltean '.' y '..', y porque por el enunciado no existen enlaces duros a directorios. Luego, los enlaces simbólicos 'l' se ignoran al no ser hard-links. Es decir, no hay ciclos.

Por último, se asume que `agregar(nombre)` se encarga de reservar memoria con malloc para aquel nombre dentro del diccionario. Esto debido a que la copia nombre utilizada en el código se declaró como un arreglo local en el stack y su espacio de memoria se invalida al salir de la función (y se sobre-escribe en llamadas posteriores). Justamente por esa razón, se asume que agregar(nombre) debe copiar el string en memoria dinámica (malloc + strcpy).

```C
Diccionario_t mapa; // dic: inode_num -> list(Strings)

void listar_hardlinks(){
    mapa.empty(); // mapa comienza vacío

    buscar_desde(2); // comienza la busqueda desde el directorio raíz '/'

    // recorrer i-nodos encontrados e imprimir sus nombres
    for(unsigned int inodo : mapa.keys()){
        printf("Inodo %u:\n", inodo);
        for(char *nombre: mapa[inodo]){
            printf(" -%s\n", nombre);
        }
    }
}

void buscar_desde(unsigned int inode_num){
    struct Ext2FSInode *dir = load_inode(inode_num);

    // cargamos los bloques del directorio (max 2 por enunciado)
    unsigned char buffer[2*BLOCK_SIZE];
    unsigned int block_addr0 = get_block_address(dir, 0);
    read_block(block_addr0, buffer);
    
    // cargar segunda parte del addr (si es necesario)
    if(dir->size > BLOCK_SIZE){
        unsigned int block_addr1 = get_block_address(dir, 1);
        read_block(block_addr1, buffer + BLOCK_SIZE);
    } 

    // recorrer todas las dir entries
    unsigned int offset = 0;
    while(offset <  dir->size){
        
        // casteo dir_entry
        Ext2FSDirEntry* entry = (Ext2FSDirEntry*)(buffer + offset);

        if(entry->record_length == 0) break;

        // copiamos el nombre asegurando '\0' final
        char nombre[entry->name_length + 1];
        strncpy(nombre, entry->name, entry->name_length);
        nombre[entry->name_length] = '\0';

        // saltear "." y ".."
        if(strcmp(nombre, ".") != 0 && strcmp(nombre, "..") != 0){
            // ¿subdirectorio o archivo? -> ver que 'l' (simb_links) son ignorados
            if(entry->file_type == 'd'){
                // subdirectorio -> recursión
                buscar_desde(entry->inode);
            } else if(entry->file_type == 'r'){
                // archivo regular -> chequear links_count
                struct Ext2FSInode *arch = load_inode(entry->inode);
                if(arch->links_count >= 2){
                    mapa[entry->inode].agregar(nombre);
                }
            }
        }

        offset += entry->record_length;
    }
}
```


### Ejercicio 2

**Funcionamiento del hardware y registros**
- Un gesto inicia al tocar la pantalla táctil (genera interrupción IRQ_TOUCH), dura mientras mantenga el contacto y termina al dejar de tocar.  

**Registros de entrada (IN) -> driver_read()**  
- TCH_STATUS; Toma el valor TCH_PRESS al iniciar el gesto y cambia a TCH_UP al finalizar.
- TCH_COORD; almacena y actualiza dinámicamente al entero que representa la coordenada (x,y) del contacto.
- TCH_TIME; mide en ms el tiempo transcurrido desde que inició el gesto (inicia en 0).

**Registros de salida (OUT) -> driver_write()**    
- PRINT_COORD; especifica la coordenada del pixel a pintar.
- PRINT_COLOR; especifica el color a utilizar.
- PRINT_OK; se escribe para confirmar y efectuar el coloreo.

#### a.

Implementar teniendo en cuenta que la lectura debe ser bloqueante mientras no esté ocurriendo ningún gesto.

```C
// struct para leer el evento tactil en driver_read
typedef stuct {
    int coord;  // TCH_COORD
    int time;   // TCH_TIME
} touch_data_t;

// struct para escribir/pintar un pixel en driver_write
typedef struct {
    int coord;
    int color;
} print_data_t

sem_t sem_touch;
bool esperando;

int driver_init(){
    sem_touch = sem_init(0);
    esperando = false;
    return request_irq(IRQ_TOUCH, irq_handler);
}

void irq_handler(){
    if(esperando) sem_touch.signal();
}

int driver_read(int *data){
    touch_data_t res;

    if(IN(TCH_STATUS) == TCH_UP){ // la pantalla no se está tocando
        // se bloquea hasta el inicio de un gesto
        esperando = true;
        sem_touch.wait();
        esperando = false;
    }

    res.coord = IN(TCH_COORD);
    res.time = IN(TCH_TIME);

    copy_to_user(data, &res, sizeof(res));
    return sizeof(res);
}

int driver_write(int *data){
    print_data_t res;

    copy_from_user(&res, data, sizeof(res));

    OUT(PRINT_COORD, res.coord);
    OUT(PRINT_COLOR, res.color);
    OUT(PRINT_OK, PRINT_OK);

    return sizeof(res);
}

int driver_remove(){
    return free_irq(IRQ_TOUCH);
}
```

Escribir el pseudocódigo de un programa de usuario que se comunique con el driver para detectar patrones de gestos (la lectura debe ser bloqueante mientras no ocurra ningún gesto):

**Patrones de gestos y acciones**:
- **Click**: un único punto de contacto sin movimiento, con duración menor a **500 ms**. Colorea el pixel tocado de **AZUL**.
- **Deslizamiento**: un punto de contacto inicial con movimiento continuo (sin soltar). Colorea cada punto detectado de **ROJO**.
- **Pulsación prolongada**: un único punto de contacto sin movimiento, con duración mayor al click ($\ge$ 500 ms). Colorea el pixel tocado de **VERDE**.

**Funciones auxiliares disponibles**:
- `int getX(int coord)`; obtiene la coordenada $x$ a partir del valor leído de `TCH_COORD`.
- `int getY(int coord)`; obtiene la coordenada $y$ a partir del valor leído de `TCH_COORD`.
- `int genCoord(int x, int y)`; toma dos coordenadas y genera el valor necesario para escribir en el registro `PRINT_COORD`.
